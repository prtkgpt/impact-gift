🛠️ How This Works

1. Search API Call

// Public API - no authentication needed for basic search const response = await fetch( `https://partners.every.org/v0.2/search/${query}` ); const data = await response.json(); console.log(data.nonprofits); // Array of nonprofit objects

2. Embed Donation Widget

// Load script once <script src="https://embeds.every.org/0.4/button.js"></script> // Initialize widget window.everyDotOrgDonateButton.createWidget({ selector: '#widget-container', nonprofitSlug: 'world-wildlife-fund', primaryColor: '#667eea', defaultDonationAmount: 50 });

3. Benefits for Your Platform

  • Zero Payment Liability: Never touch donation funds
  • No Transaction Fees: Every.org covers all costs
  • Better UX: Donors stay on your site (modal experience)
  • More Payment Options: Credit, bank, crypto, stocks, DAF, PayPal, Venmo
  • Instant Setup: No merchant accounts or compliance needed
  • 1.5M+ Nonprofits: vs. your current 8 manually-added charities
